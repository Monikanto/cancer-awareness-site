# 🎗️ Cancer Awareness & Support – Website

A simple and clean web project built to spread **cancer awareness**, inspire hope, and allow users to reach out for support.

This project includes:
- A beautiful landing page with a banner  
- Real-time inspirational quotes (using ZenQuotes API via AllOrigins proxy)  
- A contact form (no backend required)  
- Organized, industry-level folder structure  
- Ready for deployment on **Vercel**

## ✨ Features

### 🌟 Landing Page  
A minimal, clean hero section promoting awareness and hope.

### 💬 Real-Time Quotes  
Fetches inspirational quotes from ZenQuotes using a CORS-safe proxy:
```

[https://api.allorigins.win/get?url=https://zenquotes.io/api/random](https://api.allorigins.win/get?url=https://zenquotes.io/api/random)

````

### 📩 Contact Form  
Simple fields for:
- Name  
- Email  
- Message  

(No backend needed)

### 🧹 Industry-Level Code  
- Separated HTML/CSS/JS  
- Easy to maintain and expand  
- Works across all browsers

---

## 🔌 API Used
### ZenQuotes API (via AllOrigins)
Used to fetch real-time motivational quotes related to positivity and strength.
